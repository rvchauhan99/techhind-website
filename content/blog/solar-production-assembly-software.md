Indian Solar EPC companies that kit inverter packages, junction boxes, or combiner units in-house still run many of those steps in Excel. That breaks the moment finished goods need serial history, accurate stock, and a clean handoff into B2B dispatch or project installation.

**Solar production / kit assembly** belongs inside the same **Solar CRM / Solar Management System** that already runs leads, quotations, inventory, and service — not in a separate MES that never sees your warehouses or serials.

## Production is not field fabrication

techHind keeps two paths clear:

- **Production / Assembly** — warehouse kitting: BOM → work order → picklist → booking → finished-good stock
- **Fabrication & Installation** — project site build and install after the sale

Sales or project Bill of Materials used on quotations is also separate from the **manufacturing BOM** that backs work orders.

## What warehouse teams need

A production loop that stays honest with inventory:

1. Define a versioned **BOM** (components, optional lines, labour/machine/overhead costs)
2. Create a **work order**, review shortages, and approve to freeze the BOM snapshot
3. Print a shortage-aware **picklist PDF**
4. Post an **assembly booking** that issues components and receives good (and optional rejected) finished goods in one step
5. Trace **serial genealogy** from finished-good serial back through the booking to consumed component serials

Scrap, rejection warehouses, and substitute components are controlled exceptions — not spreadsheet edits after the fact.

## How it fits the full Solar CRM

Kit assembly sits between procurement and sales/execution:

- Components arrive via purchase orders and inward
- Production consumes them and returns finished goods to stock
- FG stock feeds B2B shipments or project dispatch
- Lead → quote → order → install → payments → AMC continues in the same platform
